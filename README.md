Система управления корпоративным обучением (LMS)
Веб-приложение для организации корпоративного обучения сотрудников с ролевым разграничением доступа, автоматической проверкой знаний и встроенным модулем выполнения программного кода.

О проекте
Система предназначена для IT-компаний и технических организаций, которым необходима собственная платформа для обучения сотрудников без зависимости от дорогостоящих сторонних сервисов.
Администраторы создают учебные курсы, наполняют их теоретическим материалом, проверочными вопросами и практическими заданиями по программированию. Сотрудники проходят курсы в удобное время, отвечают на вопросы и отправляют решения задач на автоматическую проверку. Система фиксирует результаты и предоставляет аналитику.

Возможности системы
Для сотрудников:

Регистрация и вход в систему
Просмотр каталога доступных курсов
Последовательное прохождение уроков с теоретическим материалом
Ответы на проверочные вопросы с мгновенной проверкой и пояснениями
Выполнение практических заданий по программированию с автоматической проверкой
Просмотр личной статистики и результатов по всем курсам
Визуализация прогресса обучения в виде интерактивных графиков

Для администраторов:

Полное управление каталогом курсов — создание, редактирование, удаление
Управление содержимым курсов — уроки, вопросы, варианты ответов
Создание практических заданий по программированию с тест-кейсами
Просмотр списка всех зарегистрированных пользователей
Доступ к сводной аналитике системы

Установка и запуск
Шаг 1. Клонирование репозитория
Скачайте исходный код проекта на свой компьютер:

cd название-репозитория
Шаг 2. Настройка базы данных
Войдите в MySQL и создайте базу данных:
sqlCREATE DATABASE lms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
Выполните скрипт создания таблиц и начальных данных:
bashmysql -u ваш_логин -p lms < schema.sql
Шаг 3. Настройка переменных окружения
Создайте в корневой директории проекта файл .env со следующим содержимым:

DB_PORT=3306
DB_USER=ваш_логин_mysql
DB_PASSWORD=ваш_пароль_mysql
DB_NAME=lms
PORT=8080
JWT_SECRET=придумайте-секретный-ключ-минимум-32-символа
Шаг 4. Установка зависимостей
bashgo mod tidy

## API

Все запросы к защищённым маршрутам требуют заголовка:
```
Authorization: Bearer <токен>
```

### Аутентификация

| Метод | Адрес | Описание |
|-------|-------|----------|
| POST | `/api/login` | Вход в систему |
| POST | `/api/register` | Регистрация нового пользователя |

### Для сотрудников

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/api/profile` | Данные текущего пользователя |
| GET | `/api/courses` | Список всех курсов |
| GET | `/api/courses/{id}/lessons` | Уроки и вопросы курса |
| GET | `/api/course-results` | Результаты прохождения курсов |
| POST | `/api/course-results` | Сохранить результат прохождения |
| GET | `/api/tasks` | Список заданий по программированию |
| POST | `/api/submit` | Отправить решение на проверку |
| POST | `/api/compile` | Выполнить код (без авторизации) |
| POST | `/api/question-answers` | Сохранить ответ на вопрос |
| GET | `/api/question-answers` | Получить ответы пользователя |

### Для администраторов

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/api/admin/courses` | Список всех курсов |
| POST | `/api/admin/courses` | Создать курс |
| PUT | `/api/admin/courses/{id}` | Обновить курс |
| DELETE | `/api/admin/courses/{id}` | Удалить курс |
| GET | `/api/admin/users` | Список пользователей |
| GET | `/api/admin/analytics` | Аналитика системы |
| POST | `/api/admin/courses/{id}/lessons` | Создать урок |
| PUT | `/api/admin/lessons/{id}` | Обновить урок |
| DELETE | `/api/admin/lessons/{id}` | Удалить урок |
| POST | `/api/admin/courses/{id}/questions` | Создать вопрос |
| PUT | `/api/admin/courses/{id}/questions/{qid}` | Обновить вопрос |
| DELETE | `/api/admin/courses/{id}/questions/{qid}` | Удалить вопрос |
| POST | `/api/admin/tasks` | Создать задание |
| PUT | `/api/admin/tasks/{id}` | Обновить задание |
| DELETE | `/api/admin/tasks/{id}` | Удалить задание |
| POST | `/api/admin/tasks/{id}/test-cases` | Добавить тест-кейс |
